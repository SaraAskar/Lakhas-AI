# 📖 Project Overview

**Lakhas** (لخّص) is an AI-powered document intelligence web application designed to help users summarize, analyze, and query complex PDF documents using open-source Large Language Models (LLMs).

Built on a **Retrieval-Augmented Generation (RAG)** architecture:
1. **PDF Processing:** Documents are parsed and split into semantic chunks.
2. **Vector Store:** Embeddings are generated and indexed using **FAISS** for fast semantic search.
3. **LLM Chain:** Queries and prompts are processed using `Qwen2.5` models via Hugging Face.
4. **Structured Reports:** Results are formatted into clean, organized sections.

---

# ✨ Key Features

* 📄 **Multi-PDF Support:** Upload one or multiple PDF documents easily.
* 🎯 **Custom Focus:** Summarize documents while targeting specific sections (e.g., payment terms, deadlines).
* 💬 **Document Q&A:** Grounded conversational query system in both Arabic and English.
* ⚖️ **Document Comparison:** Compare key differences and similarities across multiple files.
* 🌍 **Multilingual Capabilities:** Powered by multilingual embedding models.

# 🛠️ Technologies & Tools Used

* **Language:** Python
* **Frontend/UI:** Streamlit
* **RAG Framework:** LangChain
* **Vector Database:** FAISS
* **LLM & Embeddings:** Hugging Face Transformers (`Qwen/Qwen2.5-3B-Instruct`, `paraphrase-multilingual-MiniLM-L12-v2`)
* **Environment:** Kaggle Notebooks (GPU T4) & Cloudflare Tunnel
